# GitHub 发布前检查清单

## 数据与隐私

- [ ] 确认汇总指标可以对外公开。
- [ ] 确认 `figures/gallery/` 中完整四模型对比画廊具有公开权限；如有不能公开的样本则在提交前删除对应图片。
- [ ] 确认图表和报告中没有受试者、内部项目、服务器、用户名或绝对路径信息。
- [ ] 不提交画廊之外的原始实验室图片、可视化增强图片、全量预测掩膜或无法确认来源的数据。

## 模型和环境

- [ ] 不提交 `.venv`、Conda 环境目录、缓存或 Docker 镜像。
- [ ] 不提交 `.pt`、`.pth`、`.ckpt`、`.onnx` 等模型权重。
- [ ] 保留准确的模型名称、版本、来源链接、许可证和获取日期。
- [ ] 如需严格复现，在独立清单中记录权重 SHA-256，而不是将权重放入仓库。

## 仓库质量

- [ ] 运行 `python -m pip install -e ".[test]"` 和 `pytest`。
- [ ] 检查 README、报告和图片链接。
- [ ] 根据代码、报告、图表的实际权属决定是否添加 MIT、Apache-2.0 或其他许可证；不确定时先不要添加许可证。
- [ ] 创建 GitHub 仓库后，将真实 URL 回填到 `cellpose-kit` 与本仓库 README。
- [ ] 提交前运行 `git status`，确认没有大文件、密钥或无关内容。
